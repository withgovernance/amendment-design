The name of a field is not a placeholder

Left column carries components.input-label; right column is the shipped form, where First name, Last name and Phone number exist only as placeholder text. Read the right column and then read it again with a value typed into it.

The cost of the left column is one label row per field. The cost of the right one is that the field's name is set in the 38% rung — and color.aurora.tertiary-rung already says that rung is decorative only, that it clears 4.5:1 nowhere, and that placeholders are what it is for. A placeholder is an example of the expected value. It was never the name of the field, and the second row shows what is left of the name once someone types.

The invalid state takes --color-danger on light and --color-danger-soft under inversion, which is color.ink-switch-is-palette-wide and not a decision this specimen made: the base token measures 2.95:1 as ink on the dark card and 2.59:1 as a ring, so a single red across both schemes fails the state that exists to be noticed.

Rest, focus, filled and disabled follow components.input. Invalid, hint, textarea height and the consent row have no entry in the spec — see RATIFY.md. Nothing here is ratified.
