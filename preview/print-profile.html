Print — the mailed letter

Paper is not a degraded screen. It is this register's home. paper-cream, the emboss, the guilloche, the ledger number and a Scotch roman are all imitations of paper, so print is the one transport where the ink layer is literally true — and the only one where the aurora cannot exist, which costs nothing, because the aurora never carried meaning.

Ink is re-based, not flattened. The 87/55/38 scale is how ink sits on a page, not a screen affordance — so print re-bases it rather than deleting it.

It is a profile
No new tokens — the same ink layer rendered by poorer machinery. With one addition no profile has needed before, a requires: list, because paper has content requirements the screen has no equivalent for: the user's postal address and the office's.
The sheet is
the canvas
Cream does not print. A cream fill is an ink wash across a whole page, it bands on consumer printers, and the stock already has a colour. The canvas token was always standing in for this.
The emboss
cannot print
It is a deformation of a sheet; a printer can only print a picture of one. Rendered here rather than predicted: it comes out a pale grey ring — all shadow, no relief — on the very artifact whose authority it was carrying. A faint ring is worse than a smudge, because a smudge at least looks like an accident. The ledger number carries the proof instead — registers.issued.proof-rule load-bearing in a third transport.
The measure
6.5in, set by the margin. Paper takes its measure from the margin, not from a character count — and ch does not travel here for the same reason it was retired everywhere else.
Signature
Canonical here, not proposed. On screen the dotted rule anticipates an act; on paper the act happens. 0.4in of clear space, and the printed name is mandatory — a hand-signed name is not always legible and the recipient has to know who wrote.
Ledger number
Printed as one line in the closing, and the one place a user may suppress it: on a mailed letter it also discloses that the letter came through a platform.
Past one sheet
break-inside: avoid is unobeyable. A continuation header on every sheet after the first — surname, subject, ledger number, page n of m. Never strand a line; never break between the closing and the signature.

measuring…

The sheets are scale models, not chrome. Each is authored at true US Letter geometry — 816 × 1056px at 96px/in — and shown at 53%, so type set at 11.5pt renders about 8px here. That is the one licensed way a specimen may render below the 12px floor, and it is stated in the file rather than assumed.
