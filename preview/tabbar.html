The spec
Items
A curated five, not the whole nav. Actions and Tracked live in the account menu. Both navs compose from one list so they cannot drift.
Labels
12px chrome-width uppercase — the floor, no chrome exception. Fits because every item defines shortLabel; the widest uses 72% of its 75px slot.
Active
Phosphor icon regular → fill plus Midnight Indigo on icon and label. No motion — chrome is still.
Target
Explicit 44×44 minimum per tab. Type size does not get there on its own: the two shortest labels measure 43.3 and 43.6px.
Safe area
padding-bottom: max(8px, env(safe-area-inset-bottom)), and the spacer grows to match.
Hidden on
/conversation/* and /action/* — composing surfaces surrender the chrome. Signed-out users get no bar.

Known divergence: production ships 10px labels and no safe-area inset. Spec ahead on both; the code migrates. The rule this component produced: a component with a touch target declares its own minimum, measured, in its own spec entry — a11y.targetSize has said 44×44 all along and was cited by nothing, which is how a tab reached 40px.
