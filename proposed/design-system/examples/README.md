# Examples

End-to-end composition walkthroughs. Each shows how primitives + civic accents + patterns assemble into a real screen.

Use these when:
- You're building a new surface and want to see the assembly logic
- You're verifying that your composition matches the system
- You need a reference for the order in which elements appear on a page

| File | Surface | Pages composed |
|---|---|---|
| [home.md](./home.md) | Reading Room (entry) | Home with conversation starter hero |
| [conversation.md](./conversation.md) | Reading Room | Active conversation with streamed AI reply |
| [bill-page.md](./bill-page.md) | Archive | Bill detail with sponsors, vote history, paper canvas |
| [letter-flow.md](./letter-flow.md) | Writing Desk → Receipt | Letter compose → seal & send → Receipt |

The examples are **opinionated about composition order** (what goes top to bottom, what sits in sidebar) — that ordering is part of the system, not arbitrary. Don't reshuffle without a reason.
