Signatures only. A co-sign, an endorsement, a pledge, a sent letter — a person's name at the moment they put it to something. Never a heading, never UI, never a display face: the ban on script as system typography stands, and this is not typography but an artifact of an act. An uploaded signature image wins wherever one exists. The face sits small on the body, so --signature-optical-scale brings it up to the visual size of the type around it, and the role never clips — script swashes overhang their box.
